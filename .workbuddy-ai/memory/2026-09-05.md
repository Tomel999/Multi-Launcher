# 2026-09-05

## NSIS build failure fix
- Problem: `makensis not found` in GitHub Actions windows-latest runner.
  Build step succeeded (wails only warns), but Package step failed because
  no `*-installer.exe` was produced.
- Root cause: choco installs NSIS to varying paths depending on runner image.
  Old code only checked `/c/Program Files (x86)/NSIS`.
  GITHUB_PATH doesn't apply within the same job's bash shells.
- Fix: Rewrote Ensure NSIS step with `find_makensis()` function that searches
  6 common locations + falls back to `find /c/` scan. Each subsequent step
  (Build, Package) independently resolves makensis path.
- Also upgraded Node from 20 (deprecated) to 24.
- Files modified: `.github/workflows/build.yml`
